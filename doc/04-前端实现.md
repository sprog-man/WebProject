## 2. 路由

使用 `HashRouter`，适合静态托管和避免后端路由冲突。

| 路由 | 页面 | 保护 |
| --- | --- | --- |
| `#/login` | 登录/注册 | 已登录时跳转工作台 |
| `#/` | 工作台 Dashboard | 需要登录 |
| `#/projects/:projectId` | 编辑器 | 需要登录 |
| `#/settings/ai` | AI 设置 | 需要登录 |
| `*` | 重定向到 `#/` | — |

`RequireAuth` 在认证加载中显示全屏 Loading；未登录跳转 `#/login`。

## 3. 认证与全局状态

`AuthContext` 负责：

- 应用启动时：
  1. `api.init()` 获取 CSRF。
  2. `api.me()` 获取当前用户。
  3. 失败则视为未登录。
- 登录/注册后写入 `user`。
- 退出时调用 `api.logout()`，无论成功都清空 `user`。
- 监听 `aster:unauthorized` 事件；任何接口返回 401 时自动清空用户。

`api.ts` 的 CSRF 处理：

- 先从 `XSRF-TOKEN` Cookie 读取。
- 没有则请求 `/api/auth/csrf`。
- 非 GET/HEAD/OPTIONS 请求自动加 CSRF Header。
- 403 时清空 token，重新获取并重试一次。

## 7. 画布 CanvasPanel

文件：`frontend/src/editor/CanvasPanel.tsx`

### 7.1 设备尺寸

| 设备 | 设计宽度 |
| --- | --- |
| 桌面 | 1180px |
| 平板 | 834px |
| 手机 | 390px |

### 7.2 自动缩放

- 用 `ResizeObserver` 监听画布容器宽度。
- 可用宽度 = 容器宽度 - 水平内边距（<760px 用 24，否则 56）。
- `zoom = min(1, 可用宽度 / 设计宽度)`。
- 页面帧用 `transform: scale(zoom)`，`transform-origin: top left`。
- 外层 `.page-frame-shell` 的宽高设为 `设计宽度 * zoom` 和 `页面高度 * zoom`，避免缩放后布局仍按原始宽度撑开、导致右侧被裁切。
- 用第二个 `ResizeObserver` 监听页面帧高度，图片加载或内容变化后自动更新 shell 高度。
- 状态栏显示设计宽度和缩放比例，例如 `1180 px · 62%`。

### 7.3 工具栏

- 桌面/平板/手机切换。
- 撤销/重做，按钮根据历史栈禁用。
- 编辑/预览切换：
  - 编辑模式：文字 `contenteditable`，图片显示“更换图片”按钮，可选中。
  - 预览模式：不可编辑，清除选中。
- 状态栏显示项目名、区块数、提示和保存指示。

### 7.4 空画布

当 `sections.length === 0`：

- 显示 `EMPTY CANVAS`、标题“从一句话开始”和说明。
- 提供“开始描述页面”按钮，打开聊天抽屉。

## 8. 渲染器 PageRenderer

文件：`frontend/src/renderer/PageRenderer.tsx`  
样式：`frontend/src/renderer/page.css`

### 8.1 渲染模式

`PageRenderer` 同时用于：

- 编辑器画布。
- 工作台项目缩略图。
- 静态导出。

参数：

| 参数 | 作用 |
| --- | --- |
| `spec` | 页面数据 |
| `editMode` | 是否可编辑 |
| `selection` | 当前选中字段 |
| `onSelect` | 选中回调 |
| `onCommitText` | 文字提交回调 |

### 8.2 文字编辑

`EditableText`：

- 根据传入的 `as` 渲染 `span/div/h1/h2/h3/p`。
- 编辑模式下设置 `contentEditable`。
- 点击或聚焦时上报 `{ sectionId, path, kind: 'text', label }`。
- 失焦时提交 `innerText`。
- 单行字段会把换行折叠为空格并 trim。
- 多行字段保留换行，最多连续两个空行。
- 空内容会恢复到原值。
- Esc 取消本次修改并 blur。
- Enter（单行）提交并 blur。
- 粘贴时只取纯文本，避免带入外部 HTML。
- `useEffect` 在外部值变化且当前未聚焦时同步 `innerText`。

### 8.3 图片编辑

`EditableImage`：

- 渲染 `<img>`，支持 `objectFit`。
- 编辑模式下可点击选中。
- 显示“更换图片”按钮。
- 键盘 Enter/Space 可选中。
- 用 `role="button"` 和 `tabIndex` 提升可访问性。

### 8.4 主题和组件

根节点：

```text
page-root
├─ data-mode = ink / paper / forest
├─ data-font = serif / sans
└─ CSS 变量：--accent / --title-scale / --body-scale / --radius / --space
```

组件渲染通过 `SectionRenderer` 的 switch 分发。未识别组件返回 null；服务端校验会提前阻止未知组件。

## 11. 编辑器状态管理

文件：`frontend/src/store/editor.ts`

### 11.1 核心状态

| 字段 | 作用 |
| --- | --- |
| `projectId` / `projectName` | 当前项目 |
| `spec` | 当前页面数据 |
| `version` | 当前项目乐观锁版本 |
| `messages` | 对话消息 |
| `selection` | 当前选中的字段 |
| `tab` | 属性面板 Tab |
| `editMode` | 编辑/预览 |
| `device` | 桌面/平板/手机 |
| `saveStatus` | saved/dirty/saving/error |
| `sending` | AI 请求中 |
| `loading` | 项目加载中 |
| `history` / `future` | 撤销/重做栈（最多 60） |
| `changeCounter` / `savedCounter` | 判断是否有未保存改动 |
| `interactionSnapshot` | 滑块等连续交互的起始快照 |
| `lastSavedAt` | 最近保存时间 |

### 11.2 自动保存

- 任何修改调用 `touch()`：
  - `changeCounter += 1`。
  - `saveStatus = 'dirty'`。
- `queueAutosave()` 900ms 防抖。
- 保存时记录 `counter`，请求 `PUT /draft`。
- 成功后：
  - 更新 `version`。
  - `savedCounter = counter`。
  - 如果期间又有修改，保持 dirty 并再次排队。
- 失败：
  - `saveStatus = 'error'`。
  - Toast 错误。
- 同一时间只允许一个 in-flight 保存；后续保存会等待当前 Promise。

### 11.3 撤销/重做

- 普通修改在变更前把当前 `spec` 深拷贝进 `history`。
- 滑块等连续交互：
  - `beginInteraction` 记录起始快照。
  - `endInteraction` 如果内容变化，把起始快照压入历史。
- `undo`：历史栈弹出，当前 spec 压入 future。
- `redo`：future 弹出，当前 spec 压入 history。
- 历史最多 60 条。
- 撤销/重做后也触发自动保存。
- 快捷键：
  - `Ctrl/Cmd + Z` 撤销。
  - `Ctrl/Cmd + Shift + Z` 重做。
  - `Ctrl/Cmd + S` 保存。
  - 输入框/文本域/contentEditable 聚焦时，只允许保存，不允许撤销/重做。

### 11.4 AI 发送

- 发送前最多循环 3 次确保草稿保存完成。
- 先插入临时用户消息，服务端返回后替换。
- `changed` 为真：
  - 记录历史。
  - 替换 spec。
  - 增加 changeCounter，同时把 savedCounter 对齐（因为服务端已保存）。
  - saveStatus = saved。
- 失败：
  - 移除临时消息。
  - 解除 sending。
  - Toast 错误。

### 11.5 fieldMeta

用户修改文字、图片时会写入：

```json
{
  "hero.props.title": { "source": "user" }
}
```

当前只记录，不参与 AI 修改保护。后续可作为「用户锁定字段」的基础。

## 13. 静态导出

文件：`frontend/src/lib/export.tsx`

- 页面为空时拒绝导出并提示。
- 深拷贝 spec，避免修改编辑器状态。
- `collectImages` 收集首屏和画廊图片。
- 每张图片：
  - `fetch(original, { credentials: 'include' })`。
  - 同一个 src 只下载一次。
  - 写入 `assets/image-{index}.{ext}`。
  - 替换导出副本中的 `src` 为相对路径。
- 用 `renderToStaticMarkup(<PageRenderer spec={exported} />)` 生成 HTML。
- 转义标题和描述。
- 内联 `page.css`。
- 保留 Google Fonts 外链。
- 生成 ZIP 并下载 `项目名.zip`。
- 文件名会清理 Windows 非法字符。

**已验证**：

- 内置 SVG 会写入 `assets/image-N.svg`。
- 上传的 PNG 会写入 `assets/image-N.png`。
- 导出 HTML 不包含 `/api/assets` 引用。
- 图片数量和引用正确。

**注意**：当前不是把图片转成 data URL，而是下载到 `assets/`；这仍然满足“离线静态目录 + 相对引用”的部署方式。

## 15. 当前前端限制

- 没有独立组件注册表，新增组件需要改多个位置。
- 导航链接、首屏图片下方标签等字段暂无可视化编辑入口。
- 没有属性面板的“区块排序/增删”入口，结构变化主要依赖 AI。
- 没有版本历史 UI。
- 没有表单校验的国际化。
- 代码分割未做，Vite 构建提示主 chunk 约 719KB（gzip 约 219KB）。
- 窄屏真实视口尚未完整回归。

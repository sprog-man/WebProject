## 1. 当前结论

Aster / WebPorduce 已经完成一个可运行的 MVP：

- 用户能注册、登录、创建工作台项目。
- 用户能通过对话生成完整页面。

- 用户能通过属性面板修改主题、字号、布局。
- 修改能自动保存，并支持撤销/重做。
- AI 能对已有页面做局部修改。
- 页面能导出为 `index.html + assets/` ZIP。
- 后端完整构建、API 冒烟测试通过。
- 开发环境已实际启动并走查主要链路。

但还不能直接称为「生产完成」：

- 真实 DeepSeek 未验证。
- Docker / PostgreSQL 未验证。
- 窄屏真实视口未完整回归。
- 缺少端到端自动化。

## 6. 已知问题与限制

### 6.1 功能限制

| 问题 | 影响 | 建议 |
| --- | --- | --- |
| 无版本历史 UI | 已有快照但用户看不到、不能恢复 | 增加历史列表、预览、恢复 |
| 手工保存不写快照 | 用户手工修改无法回溯到具体版本 | 增加手动快照或自动周期快照 |
| `fieldMeta` 未参与 AI 保护 | AI 仍可能改用户字段 | Prompt 显式列出锁定字段 + Patch 拦截 |
| 导航 links 不可编辑 | 只能通过 AI 改 | 增加链接列表编辑 |
| 首屏 mediaLabel 不可编辑 | 只能通过 AI 改 | 加入属性面板 |
| 无区块增删/排序 UI | 结构变化依赖 AI | 增加结构编辑器 |
| 对话接口无版本检查 | 多标签可能覆盖 | 请求增加 expectedVersion |
| 项目列表返回完整 spec | 项目多时响应大 | 摘要 DTO + 缩略图字段 |
| 删除项目不清理图片文件 | 存储残留 | 定时清理或对象存储生命周期 |
| 导出为客户端打包 | 大页面可能卡顿 | 服务端异步导出 |
| Session 内存存储 | 重启掉登录、多实例不共享 | Spring Session JDBC/Redis |

### 6.2 验证缺口

| 缺口 | 风险 | 优先级 |
| --- | --- | --- |
| 真实 DeepSeek 未测 | Prompt 和解析在真实模型上可能不稳定 | P0 |
| Docker/PostgreSQL 未测 | 生产启动可能失败 | P0 |
| 390/900/700 窄屏未实测 | 移动端布局可能有溢出或遮挡 | P0 |
| JPG/WebP/GIF 未逐一测 | 某些格式上传失败 | P1 |
| 8MB 边界未测 | 前后端限制可能不一致 | P1 |
| 无 E2E | 回归依赖手工 | P1 |
| 无真实浏览器兼容矩阵 | Safari/Firefox 可能有问题 | P1 |

### 6.3 安全与运维缺口

- 无登录限流和验证码。
- 无邮箱验证。
- 无 CSP。
- 上传只校验 MIME，未校验文件头。
- 无对象存储。
- 无监控和告警。
- 无数据库备份脚本。
- 无 CI/CD。
- 无依赖漏洞扫描。
- 生产 Cookie Secure 需要 HTTPS 配合。
- H2 控制台必须在生产关闭。

### 6.4 工程限制

- 当前目录不是 git 仓库，所有改动未提交。
- 前端主 chunk 约 719KB，gzip 约 219KB，未做代码分割。
- 没有统一组件注册表，新增组件需要改渲染器、校验器、提示词、属性面板、导出图片收集。
- 没有 API 版本前缀。
- 没有 OpenAPI 文档。
- 测试主要覆盖后端 API，前端交互没有自动化。

## 8. 交付说明建议

向使用者交付时，建议说明：

1. 这是可运行的 MVP，不是最终生产版本。
2. 默认 Mock AI，配置 Key 后切换 DeepSeek。
3. 本地开发用 H2，无需安装数据库。
4. 生产建议 Docker Compose + PostgreSQL。
5. 导出结果是静态目录，可直接部署到 Nginx/对象存储静态托管。
6. 当前只支持 6 类受控组件，不支持任意 HTML。
7. 窄屏、真实 DeepSeek、Docker 三项需要在使用环境中补验。
8. 开发测试账号和临时数据不要用于生产。
